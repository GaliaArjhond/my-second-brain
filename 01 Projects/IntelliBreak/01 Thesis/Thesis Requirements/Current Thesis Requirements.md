# Current Thesis Requirements

## Target Users
- Virtual Assistants
- Work-from-Home (WFH) professionals

## Application Scope
- Web-based application
- Designed specifically for Virtual Assistants and Work-from-Home professionals
- Accessed through a web browser using a desktop or laptop computer with an internet connection

## Core Functional Requirements
- Allow users to create, organize, update, and complete their daily tasks using a checklist
- Monitor users' working hours, completed tasks, break times, lunch schedules, and inactive periods
- Provide user registration and login
- Include task management functionality
- Include productivity monitoring
- Include work history tracking
- Include recommendations system
- Include a dashboard where users can view their work progress and productivity reports

## Machine Learning
- Use machine learning to analyze users' work habits and identify patterns of overworking or underworking
- Analyze information such as working hours, completed tasks, break times, lunch schedules, and inactive periods
- Provide personalized recommendations based on users' daily work activities
- Encourage users to take breaks, avoid working for too many hours, and maintain a healthy balance between work and personal life

## Recommendations
- Provide personalized recommendations that encourage users to maintain a healthy balance between work and personal life
- Provide recommendations that help users take regular breaks
- Provide recommendations that help users avoid working for too many hours
- Provide recommendations that help users maintain a healthy work-life balance
- Provide recommendations that match the user's actual work routine (not fixed reminders)
- Provide suggestions that are useful and meaningful based on user behavior analysis

## Dashboard and Reports
- Display users' productivity, work history, completed tasks, and recommendations through a simple dashboard
- Allow users to view their work progress and productivity reports

## Software Evaluation
- Evaluate the system based on the ISO/IEC 25010 Software Quality Model
- Evaluate in terms of functionality, usability, reliability, performance efficiency, security, maintainability, portability, and compatibility

## Scope Limitations
- The system is intended only for Virtual Assistants and Work-from-Home professionals
- The application is web-based and will not include a mobile application
- The system only monitors information recorded within the application, such as working hours, completed tasks, break times, lunch schedules, and inactive periods
- Recommendations are based only on the information collected by the system and the machine learning model
- The system is designed to provide recommendations only and will not replace the performance evaluation conducted by employers or clients
- The application does not include payroll, attendance monitoring, client communication, video conferencing, or project management features
- The study will evaluate the system using the ISO/IEC 25010 Software Quality Model

## Theoretical Foundations
- Work-Life Balance Theory
- Self-Determination Theory
- Concept of Machine Learning Recommendation Systems
