# Thesis Format Guide

## Chapter 1 — Project Rationale

Required sections:
- Introduction
- Research Gap
- Review of Related Literature and Studies
- Objectives of the Study
  - General Objective
  - Specific Objectives
- Scope and Delimitation
- Theoretical Framework (Optional)
- Conceptual Framework
- Hypothesis of the Study (if applicable)

Important Chapter 1 guidance:
- Introduction should begin with a meaningful opening/teaser.
- Include relevant DYCI core values where appropriate.
- Use foundational studies in the introduction and reserve other literature for the RRL.
- Background may follow TIOC: Trends, Issues, Objectives, Contributions to Theory.
- Use a funnel approach or global-to-local perspective.
- Research gap must identify a specific area not addressed by current research.
- The final paragraph should address importance and purpose.

RRL:
- Review at least 10 literatures/studies.
- Organize them thematically, chronologically, or by local/foreign classification.
- Discuss findings, conclusions, and recommendations.

Scope and Delimitation:
- First paragraph should address the foundational 5W1H questions.
- Second paragraph should explain delimitations.
- Distinguish researcher-chosen exclusions (delimitations) from limitations outside the researchers' control.

## Chapter 2 — System Development

Required sections:
- System Development Methodology
- Requirements Analysis
- System Design
- System Development
- System Testing
- System Implementation
- System Maintenance (Optional)
- Tools and Technologies Used
- Respondents and Setting of the Study (Optional)
- Instrument and Validation
- Data Gathering Procedure
- Statistical Treatment of Data
- Ethical Considerations

System Development Methodology should include:
- SDLC model name
- Overview
- Justification

Requirements Analysis should include:
- User and system requirements
- Requirement gathering techniques
- Functional requirements
- Non-functional requirements

System Design may include:
- Architecture
- Database design
- Process flows
- DFDs/UML/ER diagrams
- UI design

Testing may include:
- Unit testing
- Integration testing
- System testing
- User Acceptance Testing
- Bug fixing/refinement

Respondents and Setting:
- Identify sampling technique.
- Explain probability/nonprobability sampling.
- For probability sampling, explain how the sample size was determined.
- For purposive sampling, present inclusion criteria.
- Explain the study setting.

Instrument and Validation:
- Identify whether the instrument is original, standardized, adapted, or adopted.
- Describe questionnaire/interview structure rather than displaying questions.
- Explain validity and reliability.
- Content validation may involve language or field experts.
- Pilot testing guidance specifies 20 samples.
- Reliability/validity may involve a statistician and Cronbach's alpha where applicable.

Data Gathering:
- Describe the collection procedure narratively.

Statistical Treatment:
- Base statistical treatment on the research problem/SOP.
- Present formulas where quantitative analysis is used.
- Qualitative studies should use an appropriate qualitative analysis method.

Ethical Considerations:
- Explain ethical principles such as ethical approval, privacy/confidentiality, and informed consent.

## Chapter 3 — Results, Discussion, and Interpretation of Data

Required sections:
- Overview of the Chapter
- Presentation of the Developed System
- System Architecture
- System Modules and Features
- Database Design
- User Interface Design
- System Testing Results
- System Evaluation Results

System Testing:
- Functional testing
- Test cases/scenarios
- Expected vs actual results
- Pass/fail outcomes
- Non-functional testing
- Performance
- Security
- Compatibility
- Reliability

System Evaluation:
- Profile of respondents
- Number of evaluators
- Roles
- Relevant characteristics
- Evaluation criteria
- Evaluation data
- Mean/weighted mean
- Verbal interpretation
- Analysis and interpretation

Hypothesis testing is included only if applicable.

## Chapter 4 — Conclusion and Recommendations

Required sections:
- Introduction
- Summary of the Study
- Findings
- Conclusion
- Recommendations

Findings:
- Must be factual and based on collected data.
- Should connect to research questions, objectives, and hypotheses where applicable.

Conclusion:
- Must be based on findings.
- One conclusion per major finding.
- Must directly answer the research problem.
- Conclusions are analytical statements, not simple summaries.

Recommendations:
- Must be based on conclusions.
- Should be realistic and actionable.
- May include suggestions for future researchers.

## References

- Use APA or the institution-prescribed format.

## Appendices

May include:
- Survey questionnaires

- Gantt chart
- Source code
- User manual
- Screenshots
