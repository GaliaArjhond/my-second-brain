# Thesis Chapter Format

## Source

[[CAPSTONE-THESIS-FORMAT-Chapters1-4]]

## Chapter 1 — Project Rationale

- Introduction
- Research Gap
- Review of Related Literature and Studies
- Objectives of the Study
  - General Objective
  - Specific Objectives
- Scope and Delimitation
- Theoretical Framework — optional
- Conceptual Framework
- Hypothesis — if applicable

## Chapter 2 — System Development

- System Development Methodology
- Requirements Analysis
- System Design
- System Development
- System Testing
- System Implementation
- System Maintenance — optional
- Tools and Technologies Used
- Respondents and Setting — optional
- Instrument and Validation
- Data Gathering Procedure
- Statistical Treatment of Data
- Ethical Considerations

## Chapter 3 — Results, Discussion, and Interpretation of Data

- Overview
- Presentation of the Developed System
- System Architecture
- System Modules and Features
- Database Design
- User Interface Design
- System Testing Results
- System Evaluation Results
- Profile of Respondents
- Evaluation Criteria
- Presentation of Evaluation Data
- Analysis and Interpretation
- Hypothesis Testing — if applicable

## Chapter 4 — Conclusion and Recommendations

- Introduction
- Summary of the Study
- Findings
- Conclusion
- Recommendations

## References

- APA or institution-prescribed format

## Appendices

- Survey questionnaires
- Interview guides
- Gantt chart
- Source code
- User manual
- Screenshots
