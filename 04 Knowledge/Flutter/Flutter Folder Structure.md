# Flutter Folder Structure

## Concept
A Flutter project can be organized into feature-based folders
to keep related UI, logic, and data together.
## When to Use
Use feature-based organization when the application becomes
large enough that a single `screens` or `widgets` directory
becomes difficult to maintain.
## Examples
- features/authentication
- features/dashboard
- features/settings
## Common Problems
Avoid putting every widget and screen into one huge folder
