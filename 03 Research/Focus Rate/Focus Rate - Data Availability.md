## Available

| Variable | Status |
|---|---|
| Work-session duration | Directly measurable |
| Task duration | Available |
| Task switching | Potentially inferable |
| Uninterrupted task duration | Not currently measurable |
| Play/pause history | Not available |

## Important Limitation

Task play/pause transitions are not persisted, therefore true
task-switching frequency cannot currently be directly measured.
